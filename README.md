# F1 Tracker — Flutter Application

```sh
flutter pub get
flutter run -d chrome
```
## Возможности

Splash, onboarding, вход и регистрация с проверкой полей, главный экран,
календарь гонок, подробности гонки, результаты, таблица чемпионата,
поиск, избранное, напоминания, профиль и настройки.

Данные демонстрационные. Вход работает локально без сервера.
Избранное и настройки сохраняются только до перезапуска приложения.

На этом ноутбуке обнаружены ошибки Flutter при обработке не-ASCII путей.
Успешная сборка и запуск приложения пока не подтверждены.
