# F1 Tracker — Практикалық жұмыс №4

Flutter мобильді қосымшасы: **Пайдаланушы интерфейсі және локалды SQLite деректер қоры (Offline First)**.

---

## Орындалған тапсырмалар (Практикалық жұмыс №4)

### 1. Сақталатын негізгі ақпарат түрлері
1. **Трассалар / Автодромдар (Circuits)** — жарыс өтетін орындар, ұзындығы, бұрылыстар саны.
2. **Командалар / Конструкторлар (Teams)** — базасы, қозғалтқыш өндірушісі, ұпайлары, титулдары.
3. **Жүргізушілер / Пилоттар (Drivers)** — нөмірі, коды, аты-жөні, командасы, ұпайлары, подиумдары.
4. **Гран-при / Жарыстар (Races)** — күнтізбе кезеңдері, күні, айналымдар саны, өткізілу мәртебесі.
5. **Еске салғыштар (Reminders)** — белгілі бір жарыс алдындағы пайдаланушы ескертпелері.
6. **Таңдаулылар (Favorites)** — таңдалған жарыстарды сақтау.

### 2–4. 6 Entity / Model және олардың логикалық байланыстары
Әр модель үшін `id` бастапқы кілті (Primary Key), деректер типтері, `toMap()`, `fromMap()` және `copyWith()` әдістері жүзеге асырылды:
- `F1Circuit` (`id`, `name`, `country`, `city`, `lengthKm`, `turnsCount`)
- `F1Team` (`id`, `name`, `baseCountry`, `powerUnit`, `points`, `championships`, `colorHex`)
- `F1Driver` (`id`, `teamId`, `name`, `code`, `number`, `country`, `points`, `podiums`)
  - *Байланыс:* `teamId` сыртқы кілті `teams(id)` кестесіне сілтейді (`ON DELETE CASCADE`).
- `F1Race` (`id`, `circuitId`, `name`, `country`, `circuit`, `date`, `round`, `laps`, `isCompleted`, `winnerDriverId`)
  - *Байланыс:* `circuitId` -> `circuits(id)`, `winnerDriverId` -> `drivers(id)`.
- `F1Reminder` (`id`, `raceId`, `title`, `advanceMinutes`, `notes`, `createdAt`)
  - *Байланыс:* `raceId` -> `races(id)` (`ON DELETE CASCADE`).
- `F1Favorite` (`id`, `targetType`, `targetId`, `createdAt`)

### 5–7. SQLite деректер қоры (`AppDatabase`)
- **Кітапхана:** `sqflite` және кросс-платформалық (desktop, тесттер) `sqflite_common_ffi`.
- `AppDatabase.instance` синглтоны арқылы деректер қоры ашылады, шетел кілттері қосылады (`PRAGMA foreign_keys = ON;`), кестелер жасалып, бастапқы демонстрациялық деректермен (Seed data) толтырылады.

### 8–11. CRUD операциялары
- **Create (Құру):** Жаңа еске салғыш қосу (`insertReminder`), жаңа жарыс қосу диалогы (`insertRace`).
- **Read (Оқу):** Күнтізбе, рейтинг, таңдаулылар және профиль экрандарында деректерді базадан тікелей оқу.
- **Update (Өзгерту):** Еске салғышты өзгерту (`updateReminder`), жарыс күйін ауыстыру (`updateRace`).
- **Delete (Өшіру):** Еске салғышты жою (`deleteReminder`), таңдаулыдан өшіру (`deleteFavorite`).

### 12. Repository / Service қабаты
- `lib/data/repositories/f1_repository.dart` — деректер қорының барлық SQL сұраныстарын (query, insert, update, delete) оқшаулайтын сервис қабаты.
- `lib/data/store/app_store.dart` — қолданбаның реактивті күйін басқару.

### 13. Деректерді іздеу (Search)
- Жарыстарды атауы, елі, трассасы бойынша және жүргізушілер мен командаларды іздеу экранында және күнтізбе экранында іздеу функциясы.

### 14. Сүзгілеу (Filtering)
- Жарыстар күнтізбесінде үш деңгейлі сүзгі: **Барлығы**, **Алдағы** (`is_completed = 0`), **Аяқталған** (`is_completed = 1`).

### 15. Екі және одан көп параметр бойынша сұрыптау (Sorting)
- **Жарыстар бойынша:**
  1. Кезең өсуімен (`round ASC, name ASC`)
  2. Кезең кемуімен (`round DESC, name ASC`)
  3. Атауы бойынша (`name ASC, round ASC`)
  4. Атауы кемуімен (`name DESC, round ASC`)
- **Жүргізушілер бойынша:**
  1. Ұпайлар кемуімен (`points DESC, podiums DESC`)
  2. Ұпайлар өсуімен (`points ASC, name ASC`)
  3. Аты-жөні бойынша (`name ASC`)
  4. Подиумдар саны бойынша (`podiums DESC`)

### 16. Таңдаулылар (Favorites)
- Таңдаулы жарыстар SQLite-тағы `favorites` кестесіне сақталады және қосымша қайта қосылғанда сақталып тұрады.

### 17. Бос жағдайды өңдеу (Empty State)
- Егер іздеу бойынша жазба табылмаса немесе таңдаулылар/еске салғыштар бос болса, пайдаланушыға арнайы белгішесі мен түсіндірмесі бар `EmptyState` виджеті көрсетіледі.

### 18. Қателерді өңдеу (Error Handling)
- `F1DatabaseException` қателіктер класы арқылы деректер қорындағы ерекше жағдайлар ұсталып, экранда SnackBar және хабарламалар арқылы пайдаланушыға жеткізіледі.

### 19–20. Офлайн режим және деректердің сақталуын тексеру
- Барлық операциялар интернетсіз құрылғы жадындағы `f1_tracker.db` файлымен орындалады.
- Тесттер топтамасы (`flutter test`) арқылы қосымшаның деректерді қайта іске қосқанда толық сақтайтыны (persistence) тексерілді.
